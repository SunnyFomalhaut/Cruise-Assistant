# iOS Port (Cruise Assistant) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, 100% offline, native iOS port of the Cruise Assistant app in the `IOS/` directory with full feature parity to the Android version, including 3-lane timeline, SVG deck maps, facility posters, Pixie Dust gift tracking with haptic keypad, custom themes, and local offline reminders.

**Architecture:** Clean Architecture + MVVM + Modular SwiftUI, with pure Swift domain algorithms (1:1 parity with Kotlin), SwiftData/SQLite persistence, WebKit/Canvas SVG rendering, and UNUserNotificationCenter offline notifications.

**Tech Stack:** Swift 6.3 / Swift 6, SwiftUI, SwiftData / SQLite3, Observation framework, UserNotifications, CoreHaptics, Xcode 26+.

**Spec:** `docs/superpowers/specs/2026-08-23-ios-port-design.md`

## Global Constraints

- All iOS source files, resources, assets, and project configurations MUST be self-contained in the `IOS/` folder.
- Zero network dependencies; 100% offline functionality.
- Domain algorithm logic (LaneAssigner, TimelineLayout, ConflictDetector, StateroomCatalog, LocationCatalog) must strictly match Android behavior and pass full unit test suites.
- Support iOS 17.0+ on iPhone and iPad.
