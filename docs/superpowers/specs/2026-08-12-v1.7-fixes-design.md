## 2. 演出等待段冲突自动岔开第三栏

### 问题
`createVoyage` 生成预置演出时 `lane = 1` 硬编码。加 30 分钟等待段后同日多场演出同栏重叠：
- 海洋奇缘（9:30/10:00/10:30）：扩展区间 9:00-9:45 / 9:30-10:15 / 10:00-10:45，两两重叠
- 扬帆起航（13:15/14:00/14:45）：扩展区间 12:45-13:45 / 13:30-14:30 / 14:15-15:15，前两场重叠

### 修复
新 domain 纯函数（LaneAssigner.kt，可测试）：

```kotlin
/**
 * 预置演出生成时的栏位分配：优先第二栏（1），冲突则第三栏（2），再冲突回退第一栏（0）。
 * occupied 为已分配演出（按扩展区间）的 (lane, effStart, effEnd) 列表。
 */
fun assignShowLane(
    startMinute: Int,
    endMinute: Int,
    occupied: List<Triple<Int, Int, Int>>,
): Int {
    for (lane in listOf(1, 2, 0)) {
        val busy = occupied.any { (l, s, e) ->
            l == lane && overlaps(startMinute, endMinute, s, e)
        }
        if (!busy) return lane
    }
    return 0
}
```

`createVoyage` 演出生成循环：
- 按天维护 `occupiedByDay: MutableMap<LocalDate, MutableList<Triple<Int, Int, Int>>>`
- 每生成一场：`effStart = startMinute - SHOW_WAIT_MINUTES`、`effEnd = endMinute`（预置演出均为 show 类别），`lane = assignShowLane(effStart, effEnd, occupiedByDay[date])`，再将该场加入 occupied
- `CruiseEvent.lane` 用返回值，不再硬编码 1

### 预期效果（生成时验证）
- day1：扬帆起航 12:45-13:45 栏2、13:30-14:30 栏3、14:15-15:15 栏2；海洋奇遇（17:30-19:00 或 20:00-21:30）栏2
- day2：海洋奇缘 9:00-9:45 栏2、9:30-10:15 栏3、10:00-10:45 栏2；回忆、狮子王烟花栏2
- 中间场次自动岔开第三栏，其余保持第二栏

### 测试（LaneAssignerTest 或新 ShowLaneTest）
- 三场重叠场景：第一场栏2、第二场栏3、第三场回栏2
- 完全空闲 → 栏2
- 栏2/3 都冲突 → 回退栏0

## 3. 默认餐食不显示预置地点下拉

### 根因
`EventSheetViewModel` 的 categories collect 块：`iconKey` 用 `current.selectedCategoryId`（初始 null）计算 → iconKey=null → `resolvePresetMode` 返回 false；categories 流仅发射一次（无后续 DB 变化）→ `locationPresetMode` 永久 false。用户切走类别再切回（触发 `onCategorySelect`）才恢复正常。

### 修复
collect 块 iconKey 用 fallback 后的 id：

```kotlin
val resolvedId = current.selectedCategoryId ?: list.firstOrNull()?.id
val iconKey = list.firstOrNull { it.id == resolvedId }?.iconKey
```

（`selectedCategoryId` 的 copy 赋值已用同样 fallback；`iconKey` 计算同步即可。）

### 效果
新建弹窗默认选中第一个类别（餐食）→ iconKey=meal → 内置船 → `locationPresetMode=true`，下拉立即显示；切到演出同样生效；切到无目录类别（重要事项等）→ 自由输入。
