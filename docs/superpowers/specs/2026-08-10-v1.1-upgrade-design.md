# v1.1 Upgrade Design Specification

## Overview
This document specifies the design for the v1.1 release of Cruise Assistant (邮轮助手). The upgrade includes bumping the version, introducing an adaptive launcher icon for Android, and customizing the release APK build output filename.

## 1. Versioning
- `versionCode`: `2`
- `versionName`: `"1.1"`

## 2. Adaptive App Icon (Scheme A - Modern Ocean Theme)
### Design
- **Background (`ic_launcher_background.xml`)**: Ocean blue gradient layer (`#0F2027` to `#2C5364`) with subtle waves motif.
- **Foreground (`ic_launcher_foreground.xml`)**: Vector illustration of a cruise ship in clean white and gold accent lines (`#FFFFFF` and `#FFD700`), positioned within the 108x108 dp safe zone (72x72 dp viewport).
- **Adaptive Icon Descriptor (`mipmap-anydpi-v26/ic_launcher.xml` & `ic_launcher_round.xml`)**: Standard Android adaptive icon combining foreground and background drawables.

### Android Manifest Integration
Update `AndroidManifest.xml` in `<application>` tag:
- `android:icon="@mipmap/ic_launcher"`
- `android:roundIcon="@mipmap/ic_launcher_round"`

## 3. Release APK Custom Output Naming
### Naming Convention
Target filename: `CruiseAssistant-v1.1.apk`

### Gradle Configuration (`app/build.gradle.kts`)
- Configure build variant output file name dynamically using `android.applicationVariants.all`:
  ```kotlin
  applicationVariants.all {
      outputs.all {
          val output = this as? com.android.build.gradle.internal.api.BaseVariantOutputImpl
          output?.outputFileName = "CruiseAssistant-v${versionName}.apk"
      }
  }
  ```
- Ensure `./gradlew assembleRelease` produces `CruiseAssistant-v1.1.apk` in the release output directory (`app/build/outputs/apk/release/` and copied to `app/release/`).

## Verification Strategy
1. Run `./gradlew assembleRelease` to confirm build succeeds without errors.
2. Verify that the output APK is generated at `app/release/CruiseAssistant-v1.1.apk` (or `app/build/outputs/apk/release/CruiseAssistant-v1.1.apk`).
3. Verify manifest and resource linking for icons.
