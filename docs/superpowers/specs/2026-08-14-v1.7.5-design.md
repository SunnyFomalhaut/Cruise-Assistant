# v1.7.5 设计规格（登船改名+时段选择 / 餐次联动时间 / 下拉美化 / 六项修复）

## Overview
v1.7.5：三个功能（上船→登船全局改名+登船时间改 15 分钟段选择、选餐次自动调整起止时间、地点下拉美化）与六项修复（地点字段点击弹出菜单、全部地点补中文名、空标题允许、预置晚餐不写标题、($) 收费餐厅归 paid 分组、Room Service 早餐可筛）。版本 1.7.5（versionCode 13）。

## 1. 登船改名 + 登船时间选择

### 1a. 全局"上船"→"登船"
- strings.xml：所有含"上船"的文案改"登船"（onboarding 标签、事件标题、设置摘要等——grep "上船" 全部替换）
- 代码：`createVoyage` 的登船事件 `title = "上船"` → `"登船"`；`updateVoyage` 中按标题匹配系统事件的 `"上船"` → `"登船"`（**两处必须同步改**，否则更新航次时登船事件静默丢失）
- 注释里的"上船日/上船时间"同步改"登船日/登船时间"

### 1b. 登船时间改为时间段选择
- OnboardingScreen 的登船时间 TimeWheel → 下拉选择（ExposedDropdownMenuBox），选项为 15 分钟一段：
  **11:45-12:00 起，每 15 分钟一段，至 3:00-3:15 止**（60 段，跨午夜按 24h 连续排：11:45、12:00、…、23:45、0:00、…、3:00）
- 显示格式：`"12:00-12:15"`；默认选中 `12:00-12:15`
- 存储：`boardTime` 仍存段开始时刻（12:00），登船事件 duration 15 分钟 = 窗口时长，模型与 DB 不变（无迁移）
- OnboardingViewModel 新增 `onBoardTimeChange` 保持接口不变（值语义同前）

## 2. 餐次 → 起止时间联动

`EventSheetViewModel.onMealPeriodSelect`：设置餐次时同步调整时间（时长 30 分钟）：
- BREAKFAST → 08:00-08:30；LUNCH → 12:00-12:30；DINNER → 18:00-18:30；LATE_NIGHT → 22:00-22:30
- 选"全部"/零食/酒水 → 不调整时间
- 若已有地点校验/营业校验逻辑不受影响（保存时仍校验）

## 3. 地点下拉美化

LocationPicker 预置下拉菜单重设计（解决"有的条目一行有的两行、无底色无网格难分辨"）：
- **统一单行条目**：`"Deck N 区域 名称"` 单行 + ellipsis（长名截断，完整名选中后在字段显示）
- **分组标题**：粗体 + 淡灰底纹（`surfaceVariant`）+ 上下留白，视觉分隔
- **条目间分隔**：每项之间 `HorizontalDivider(alpha 0.3)` 细线
- **选中高亮**：当前已选条目 `primary.copy(alpha 0.1)` 背景
- 菜单圆角 + 阴影保持 M3 默认；最大高度 360dp 不变

## 4. 六项修复

### 4a. 地点字段点击弹出菜单
LocationPicker 下拉模式的 OutlinedTextField 加 `Modifier.clickable { presetMenuOpen = true }`（readOnly 字段整块可点，与 trailingIcon 一致）。

### 4b. 全部地点补中文名（贴合迪士尼主题）
数据文件 locations.json 的 name 字段改为"中文 英文"格式。翻译表（新建文档内附全表，73 场所）：如
- Concierge Lounge → 礼宾休息室 Concierge Lounge
- Edge → 边缘少年俱乐部 Edge
- Vibe → 活力少年俱乐部 Vibe
- Pixar Market Restaurant → 皮克斯市场餐厅 Pixar Market Restaurant
- Hollywood Spotlight Club → 好莱坞聚光灯俱乐部 Hollywood Spotlight Club
- Spellbound 等既有中文保留
- 已有中文的 15 个不变；新增翻译约 58 个（导入脚本重跑）

### 4c. 空标题允许
- `EventSheetViewModel.save()`：删除标题必填校验（`title.isBlank()` 报错分支）
- 保存时 fallback：`title.trim().ifEmpty { placeName 非空取 placeName，否则取类别名 }`
- EventCard 渲染兜底：`event.title.ifEmpty { category?.name ?: "" }`（防旧数据空标题空白卡片）

### 4d. 预置晚餐不写"晚餐"标题
`createVoyage` 晚餐事件 `title = "晚餐"` → `title = ""`（卡片经 4c 兜底显示"餐食"）。`updateDinnerEventsTime` 按 presetKey 匹配不受影响。

### 4e. ($) 收费餐厅归 paid 分组
数据导入 group 判定：名字含 `$` 优先归 paid（无论来源表）。受影响：Bacha Coffee ($)、TWG Tea ($)、Palo Café© ($)、Bewitching Boba & Brews ($)、Mike & Sulley's ($)、Palo Trattoria ($)。酒吧/快餐分组相应减少，收费餐厅分组变为 6 个。

### 4f. Room Service 早餐可筛
数据：Room Service 的 24 小时时段拆为两个：meal=breakfast 一个、meal=snack 一个（各 00:00-23:59）——早餐与零食筛选都命中。
