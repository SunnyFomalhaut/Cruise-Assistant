# v1.7 设计规格（Deck 标注 / 提醒升级 / 演出等待入场 / 地点预置下拉）

## Overview
v1.7 四项改动：(1) 层数标注从 "F" 改为 "Deck"；(2) 系统通知横幅升级 + 三个提醒点（15/5/0 分钟，设置页开关）；(3) 演出类别事件渲染"提前 30 分钟等待入场"延伸段（合并卡片、淡色斜纹），顺便缓解短演出显示不全；(4) 演出/餐饮预置地点下拉（绑定探险号，保留自定义选项），并同步预置演出地点。

## 1. 层数标注 F → Deck

统一替换所有"第几层"显示文案，格式为 `Deck N` 后跟区域/地点，带空格（与用户示例一致）：

| 位置 | 现在 | 改为 |
|---|---|---|
| `formatLocation`（卡片第 2 行、通知正文） | `10F船中花园` | `Deck 10 船中 花园舞台` |
| LocationPicker 楼层按钮 | `10F` | `Deck 10` |
| 楼层下拉项 | `10F` | `Deck 10` |
| 历史地点建议项 | `10F船中xxx` | `Deck 10 船中 xxx` |

- `formatLocation(deck: Int?, zone, placeName)` 保持签名，仅改拼接逻辑：`"Deck $deck" + zone.label + placeName`（deck=null 仍返回 null）。
- 同步更新 `LocationFormatterTest`。
- 搜索确认无其他 `"F"` 硬编码拼接点（LocationPicker 楼层控件、LocationPreset 建议项是已知的全部位置）。

## 2. 提醒系统升级

### 2a. 通知横幅升级（NotificationHelper.notifyEvent）
- `BigTextStyle`：大文本 = 标题行 + 正文行（时间 · 地点），展开显示完整信息
- `setColor(主题色)` 着色、`setVibrate`（如 `longArrayOf(0, 300, 100, 300)`）
- 频道沿用 `IMPORTANCE_HIGH`，创建时配置默认声音（`NotificationChannel` 的 `setSound` 用系统默认通知音）
- 大图标：`setLargeIcon` 从 app 图标取 bitmap（`context.packageManager.getApplicationIcon(packageName)`）
- 沿用现有记账 + `FLAG_NO_CREATE` 取消机制不变

### 2b. 三个提醒点（设置页三个开关，默认全开）
- `AppSettings` / `SettingsStore`：删除 `defaultReminderMinutes: Int`，新增 `remindBefore15: Boolean = true`、`remindBefore5: Boolean = true`、`remindAtStart: Boolean = true`（DataStore 三个 boolean key；旧 `reminder_minutes` key 数据忽略，读不到新 key 时用默认 true，即"默认全开"兼容旧用户）
- `SettingsScreen`："提前提醒"单选 → 三行开关：15 分钟前 / 5 分钟前 / 开始时
- `SettingsViewModel`：`setReminderMinutes` → 三个 setter，各自 `settingsStore` 写入 + `reminderScheduler.rescheduleAll()`

### 2c. 多闹钟排程（ReminderScheduler）
- 每个事件按三个开关排 0–3 个闹钟，触发时刻 = 事件时刻 −15 / −5 / 0 分钟
- **requestCode 保持 `eventId.toInt()` 不变**；三个闹钟用不同 **intent action** 区分：15 分钟 = `null`（与旧版本一致）、5 分钟 = `"lead_5"`、开始时 = `"lead_0"`——action 不同的 PendingIntent 互不覆盖
- 兼容性：15 分钟槽的 requestCode + action 与旧版本完全相同 → 升级后旧闹钟被自然覆盖；armed 记账仍按 eventId（一个事件排了任一闹钟即记账），rescheduleAll 取消时对三个 slot 都做 `FLAG_NO_CREATE` 查找取消
- `ReminderReceiver`：从 intent action 判断槽位，通知内容追加提醒点文案（如"还有 5 分钟开始"）——按槽位在标题/正文加前缀
- 事件级 `reminderMinutesBefore` 字段保留不用（当前无 UI 路径设置它）

## 3. 演出等待入场延伸段（合并卡片渲染）

### 3a. 范围与语义
- 所有"演出"类别（category iconKey == "show"）的事件——预置演出 + 用户自建的演出事件
- 纯渲染合成，不落库、不生成事件、无提醒；删除演出事件即消失

### 3b. 纯函数（domain/ShowPreset.kt 或新文件）
```kotlin
const val SHOW_WAIT_MINUTES = 30

/** show 类别事件的有效开始时间 = start − 30 分钟（等待入场占位）；其他事件返回原值 */
fun showEffectiveStartMinute(event: CruiseEvent): Int
```
实现：`event.categoryId` 对应类别的 iconKey 需从 Category 查——**函数签名改为接收类别信息**：
```kotlin
fun showEffectiveStartMinute(event: CruiseEvent, isShowCategory: Boolean): Int =
    if (isShowCategory) event.startMinute - SHOW_WAIT_MINUTES else event.startMinute
```
（调用方判断 `category.iconKey == "show"`；domain 函数保持纯计算、可测试）

### 3c. 三处统一使用扩展区间
- **布局**（`buildTimelineLayout`）：show 事件的布局占位按 `effectiveStart..end` 计算（折叠段/隐藏计数用扩展区间），等待段占用时间轴空间
- **冲突检测**（`findConflicts`）：show 事件按扩展区间参与重叠判定（等待段与其他事件重叠报冲突）
- **换栏**（`assignLane` / `setActive` 重算）：show 事件按扩展区间避让

### 3d. 卡片渲染（LaneCanvas + EventCard）
- show 事件卡片总高 = `minuteToDp(end) − minuteToDp(effectiveStart)`（30 分钟等待段 + 演出时长）
- 上半 30 分钟：**淡色延伸段**——斜纹背景（`linearGradient` 条纹、类别色淡化）、斜体"演出等待入场"标注、地点与时间信息显示在此段
- 下半段：现有正常渲染（类别 chip + 标题 + 时间时长）
- 15 分钟短演出 → 总高 45dp ≥ 44dp 非压缩阈值 → 标题、地点、时间全部显示（缓解显示不全）
- 卡片内部按 `event` 的类别绘制分段；`narrow` 栏（栏 2）行为保持现有 compact 逻辑

### 4c. 预置演出地点同步（ShowPreset.kt 数据更新，新航次生效）
- 扬帆起航：花园舞台 10F **船中** → Deck 10 **船尾**
- 海洋奇遇 / 回忆：迪士尼剧院 → **华特迪士尼剧院**（Deck 6 船头）

- 弹窗摘要 `presetShowsSummary()` 不含地点，不受影响

### 4d. LocationPicker 下拉模式（EventSheet 弹窗）
- 传入 `categoryIconKey: String?` + `builtInShip: Boolean`
- **show 或 meal 且内置船** → 预置下拉模式：
  - 下拉列表 = `BUILT_IN_LOCATION_CATALOG[iconKey]`；meal 按 `diningGroup` 分组展示（组标题行，不可选）
  - 底部固定"**自定义地点…**"项 → 点后切回现有自由输入模式（楼层/区域/地点名可见）
  - 选中预置项 → 填充 deck/zone/placeName
- **其他类别或自定义船** → 维持现状自由输入
- 编辑事件时：事件地点与目录某项完全匹配 → 下拉默认选中该项；不匹配 → 默认"自定义地点"
- 模式状态放 EventSheetState（`locationPresetMode: Boolean` + 当前选中项），切"自定义"后保持自由输入

## 7. 范围决策
- 等待段仅针对 show 类别事件（预置演出 + 用户自建演出），其他类别不受影响
- 事件级 `reminderMinutesBefore` 保留但不再参与排程（无 UI 路径）
- 预置演出地点变化只影响新建航次；旧航次不迁移（用户可"重建航次"）
- 不新增 Room 表/迁移；`BUILT_IN_LOCATION_CATALOG` 为代码内静态目录（延续 ShipPreset/ShowPreset 模式）
