# v1.7 候场阈值自适应实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** EventCard 的候场区两行阈值从硬编码 36dp 改为 typography 派生（fontScale 自适应）。版本号不变（8/"1.7"）。

**Architecture:** 单文件小改（EventCard.kt）：删文件级常量，Composable 内用 `with(LocalDensity.current)` 从 `labelSmall.lineHeight` 派生（`行高 × 2 + 4dp`），加一个 import。

**Tech Stack:** Kotlin, Jetpack Compose。

## Global Constraints

- 只修改 `app/src/main/java/com/cruise/assistant/ui/timeline/EventCard.kt`；提交时只 `git add` 这一个文件。
- 版本号不变（不要动 build.gradle.kts）。
- 派生公式唯一真源：`(MaterialTheme.typography.labelSmall.lineHeight * 2 + 4.dp.toSp()).toDp()`（在 `with(LocalDensity.current)` 内）。
- fontScale 1.0 时结果应为 36dp（行为不变）。
- 不新增 Room 表/迁移（DB version 4）。

### Task 1: 阈值派生

**Files:**
- Modify: `app/src/main/java/com/cruise/assistant/ui/timeline/EventCard.kt`

- [ ] **Step 1: 删常量**

删除 EventCard.kt 顶部常量区：

```kotlin
/** 候场区能显示两行内容的最小高度（两行 labelSmall 16dp + 4dp 纵向 padding） */
private val WAIT_TWO_LINE_MIN_DP = 36.dp
```

- [ ] **Step 2: 加 import**

`androidx.compose.ui.platform.LocalDensity` import 按字母序加入（`androidx.compose.ui.platform` 组内）。

- [ ] **Step 3: Composable 内派生**

把：

```kotlin
    // 候场区是否够显示两行（tier 4 用）
    val waitTwoLines = waitSegmentHeightDp >= WAIT_TWO_LINE_MIN_DP
```

替换为：

```kotlin
    // 候场区两行阈值从 typography 派生（fontScale 自适应）：两行 labelSmall 行高 + 4dp padding
    val waitTwoLineMinDp = with(LocalDensity.current) {
        (MaterialTheme.typography.labelSmall.lineHeight * 2 + 4.dp.toSp()).toDp()
    }
    // 候场区是否够显示两行（tier 4 用）
    val waitTwoLines = waitSegmentHeightDp >= waitTwoLineMinDp
```

- [ ] **Step 4: 编译验证**

Run: `./gradlew :app:compileDebugKotlin`
Expected: BUILD SUCCESSFUL（无 `WAIT_TWO_LINE_MIN_DP` 残留引用）。

- [ ] **Step 5: 提交**

```bash

git commit -m "feat: derive wait two-line threshold from typography (fontScale adaptive)"
```
