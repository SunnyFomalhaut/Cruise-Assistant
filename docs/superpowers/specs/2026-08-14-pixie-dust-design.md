# Pixie Dust（仙尘）交换记录 — 设计文档

日期：2026-08-14
状态：已与用户确认

## 背景与目标

迪士尼游轮（迪士尼探险号）有个传统：乘客装饰自己的房门，并准备很多 Pixie Dust（仙尘）小礼物互相交换。礼物通常分多个等级，用于发给不同房间或作为回礼——收到贵重的礼物要回一份更高级的。

本功能提供一个**独立于时间线的新界面**，记录两件事：

1. **发出**：给哪个房间发了什么等级的礼物 —— 核心场景是"走廊里随手记"，必须极快
2. **收到**：从哪个房间收到了什么等级 —— 本质是一份"回礼待办"，重点是看清"欠谁一份高级回礼"

房间号格式：楼层（Deck）+ 三位房间号。如 11550 = Deck 11 房间 550。

## 入口

新增路由 `pixiedust`，与时间线平级，全屏页面，返回回到时间线。两个入口：

- **时间线顶栏**：新增仙尘/魔法棒图标按钮
- **FAB 上方**：现有"新增事件"悬浮按钮上方加一个稍小的仙尘入口按钮，单手可达（走廊场景）

## 页面结构

```
┌─────────────────────────────┐
│ ← 返回    [发出] [收到]  ⚙️  │  顶 tab + 等级管理齿轮
├─────────────────────────────┤
│  统计条：发出 12 · 收到 8 ·  │  发出tab：发出总数+分等级
│  待回礼 3（豪华2 精致1）     │  收到tab：待回礼数+分等级
├─────────────────────────────┤
│  楼层：[11 ▾]                │  楼层下拉（船楼层范围，记忆上次）
│  ┌─────────────────────┐    │
│  │   5 5 0             │    │  大数字显示 + 数字键盘(0-9 ⌫)
│  └─────────────────────┘    │
│  等级：[普通] [精致] [豪华]  │  大按钮，预选上次等级
│        [ ✓ 记一笔 ]         │
├─────────────────────────────┤
│  ▼ 列表（键盘收起后可见）    │
│  11550 · 普通×2 豪华×1  ↕   │  视图切换：按房间归组 / 时间流水
└─────────────────────────────┘
```

- 默认落在**发出** tab（走廊快捷记录主场景）
- **收到** tab 同款键盘流，记录默认"未回礼"，回礼状态在列表里勾选
- 键盘区可收起，收起后列表占满剩余空间

## 数据模型（Room schema v4 → v5）

### `pixie_dust` 表（单表，方向字段区分）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | Long | 主键自增 |
| `direction` | String | `GIVEN`（发出）/ `RECEIVED`（收到） |
| `deck` | Int | 楼层 |
| `room` | String | 房间号（三位，如 "550"） |
| `levelId` | Long | 关联 `pixie_level` |
| `levelNameSnapshot` | String | 等级名快照（等级被删后历史记录仍可显示） |
| `replied` | Boolean | 仅 RECEIVED 用，默认 false |
| `note` | String | 备注，默认空，事后从编辑弹窗补 |
| `timestamp` | Long | 自动记录时刻（epoch millis） |

### `pixie_level` 表（等级，可增删改）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | Long | 主键自增 |
| `name` | String | 等级名 |
| `color` | Long | 颜色（ARGB） |
| `icon` | String | 图标标识 |
| `rank` | Int | 数值越大越贵重；排序与"贵重优先"依据 |
| `sortOrder` | Int | 管理与键盘上的显示顺序 |

默认预置 3 级：普通（灰）、精致（蓝）、豪华（金）。用户可在等级管理里自由增删改、调排序。

### DAO / Repository

- `PixieDustDao`：insert / update / delete / 按方向查全量（Flow） / 按房间查历史（用于"上次等级"预选与历史小字）
- `PixieLevelDao`：CRUD + 全量 Flow
- `PixieDustRepository` / `PixieLevelRepository`：包装 DAO，暴露 domain 层模型（`PixieDustRecord`、`PixieLevel`）

统计（发出/收到件数、待回礼数、分等级计数）在 ViewModel 层从全量 Flow 派生，不需要单独查询。

## 关键交互

### 录入（发出与收到同款键盘流）

1. 楼层下拉选层（范围 = 航次 `minDeck`–`maxDeck`，回退 1–20；记忆上次选择，存 DataStore prefs）
2. 数字键盘输入三位房号（仅 0-9 + 退格；不足三位时"记一笔"禁用）
3. 点等级大按钮（输入的房间有历史时**自动预选上次用的等级**，键盘下方小字显示"上次：豪华 ×2"）
4. 点"记一笔" → 立即入库，无确认弹窗；toast 提示后房号清空、等级保留，可连记

### 收到列表

- 排序：**未回礼在前、按等级 rank 降序**（贵重优先），已回礼沉底按时间倒序
- 每条记录有"已回礼"勾选，勾选即更新
- 录入时默认未回礼

### 发出列表

- **双视图切换**（列表顶部 ↕ 切换按钮）：
  - **按房间归组**（默认）：一房一行，显示各等级计数（如 `11550 · 普通×2 豪华×1`），按最近一次发出时间倒序
  - **时间流水**：一条一行倒序

### 编辑与删除

- 列表项点开编辑弹窗：改楼层/房号/等级/备注/已回礼，可删除
- 删除有确认

### 等级管理

- 仙尘页顶部齿轮 → 等级管理弹窗/页（与现有事项类别管理同范式）
- 增删改名称、颜色、图标、排序
- 删除有关联记录的等级时弹确认，说明历史记录将保留等级名快照显示

### 时间戳

自动记录入库时刻，列表项小字显示日期。编辑不改时间戳（保留原始时刻）。

## 统计条

页面顶部统计条，分等级彩色展示：

- 发出 tab：发出总件数 + 分等级计数
- 收到 tab：收到总件数 + 待回礼数（分等级，贵重在前）

## 错误处理

- 房号不足三位 → "记一笔"禁用
- 航次未配置楼层范围（空/0）→ 楼层菜单回退 1–20
- 删除等级有关联记录 → 确认弹窗（说明保留名称快照）
- 房号输入超三位 → 忽略多余输入（上限 3 位）

## 不做的事（YAGNI）

- 不做发出↔收到的双向关联（收到记录不强制关联到某条发出记录）
- 不记录礼物内容（只有房间+等级+事后备注）
- 不做库存管理
- 不做数据导出
- 不做多航次历史（随航程数据一起走，重置航程时一并清理）
