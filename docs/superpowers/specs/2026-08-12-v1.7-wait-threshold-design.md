# v1.7 候场阈值自适应设计规格（fontScale 派生）

## Overview
把 EventCard 的 `WAIT_TWO_LINE_MIN_DP = 36.dp` 硬编码常量改为从 `MaterialTheme.typography.labelSmall.lineHeight` 组合时派生，使系统字体放大（fontScale > 1.0）时候场区两行判定同步放大，避免第二行被裁剪。版本号不变（versionCode 8 / versionName "1.7"）。

## 1. 改动（EventCard.kt 单文件）

- 删除文件级常量 `WAIT_TWO_LINE_MIN_DP = 36.dp`
- Composable 内（`showTier` 计算前）新增：

```kotlin
    // 候场区两行阈值从 typography 派生（fontScale 自适应）：两行 labelSmall 行高 + 4dp padding
    val waitTwoLineMinDp = with(LocalDensity.current) {
        (MaterialTheme.typography.labelSmall.lineHeight * 2 + 4.dp.toSp()).toDp()
    }
    val waitTwoLines = waitSegmentHeightDp >= waitTwoLineMinDp
```

- 新增 import：`androidx.compose.ui.platform.LocalDensity`（`toSp`/`toDp` 为 Density 扩展，`with(LocalDensity.current)` 内可用；`dp` 已 import）

## 2. 行为
- fontScale 1.0：16sp × 2 + 4dp = 36dp——与现状完全一致
- fontScale > 1.0：阈值随行高同步放大，候场区两行始终放得下，不再裁剪
- tier 判定链不变（0/3/2/4/1）

## 3. 范围决策
- 只改 EventCard.kt 的 `WAIT_TWO_LINE_MIN_DP` 一处
- body 侧阈值（42/58dp）不在本次范围（涉及 bodySmall 混合行高，保持现状）
- 版本号不变；无 Room 迁移
