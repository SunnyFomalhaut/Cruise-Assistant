# v1.7.2 设计规格（半点刻度 / 晚餐同步修复 / 三栏等宽横滑 / 演出候场提醒）

## Overview
v1.7.2 四项改动：(1) 每小时高度 ≥90 时左侧时间刻度显示半点；(2) 修复引导页选的晚餐时段未同步到设置页；(3) 第三栏等宽 + 横向平移滑动（课程表式，默认第三栏半露）；(4) 演出提醒改为候场基准并新增开场前 5 分钟提醒。版本 1.7.2（versionCode 10）。

## 1. 半点刻度

- `hourTicks()` 改为返回 `(分钟, dp偏移, 是否半点)`：`step 30` 循环；整点 `%02d:00`、半点 `"%d:%02d"`（如 "5:30"）
- 半点样式（TimeRuler）：`labelSmall`、`onSurfaceVariant.copy(alpha = 0.55f)`——用字号+颜色区分
- **仅 `hourHeightDp >= 90` 时生成半点**（低于 90 不显示，避免拥挤）；折叠段内的半点与整点同样跳过
- TimelineGrid 的横向网格线仍只画整点（半点不加网格线，保持视觉干净）

## 2. 晚餐时段设置同步（bug）

根因：`OnboardingViewModel.submit()` 把 `dinnerTime` 传给 `createVoyage` 但未写 SettingsStore，设置页仍读默认 17:45。

修复：submit 的 `createVoyage(...)` 调用前加 `settingsStore.setDinnerTime(current.dinnerTime)`。

## 3. 三栏等宽 + 横向平移

- `LANE_WEIGHTS` 1/1/0.45 → **1/1/1**；`laneBoundaryFractions()` 自动随权重更新
- 栏区横向可滚动：内容总宽 = 3 × laneWidthDp，`laneWidthDp = 视口宽 × 0.4`（内容 ≈ 1.2× 屏宽）；默认位置（不滑动）第 1、2 栏全显 + 第 3 栏露一半
- 实现：TimelineScreen 的栏区（TimeRuler 右侧）包 `horizontalScroll(rememberScrollState())`，内部 Box 宽 = 3 × laneWidthDp；LaneCanvas/Grid 以该 Box 为画布（权重 1/1/1 → 三栏等宽）；TimeRuler 固定左侧不参与滚动
- 定稿模式（单栏）：内容宽 = 视口宽、不滚动，行为不变
- `narrow` 栏参数（原栏 2 特殊窄栏）随等宽化失效——EventCard/LaneCanvas 中 `narrow` 逻辑保留但恒为 false（卡片不再有"窄栏"模式）

## 4. 演出提醒候场基准

演出类别（iconKey=="show"）事件：提醒基准 = `startTime − 30 分钟`（候场开始）；非演出不变。

| 槽位 | 演出 | 非演出 |
|---|---|---|
| slot 0（15 前） | 候场前 15（开场前 45） | 开场前 15 |
| slot 1（5 前） | 候场前 5（开场前 35） | 开场前 5 |
| slot 2（开始时） | 候场开始（开场前 30） | 开场时刻 |
| slot 3（新增） | 开场前 5（自动加，无开关） | 无 |

- 通知正文（演出）："还有 N 分钟开始候场" / "现在开始候场" / "还有 5 分钟开场"
- slot 3 action `"show_open_5"`（requestCode 不变）；取消循环覆盖 0..3
- `SLOT_LEAD_MINUTES` 不变（slot 0/1/2 的提前量相对各基准）；调度循环内按类别算基准：`baseMs = 演出 ? startMs − 30min : startMs`
- MAX_SCHEDULED 每演出最多 4 闹钟，500 上限足够
