# v1.6 收尾改进实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 menuAnchor 弃用警告、引导页默认选中探险号、落实预置演出遗留的 6 项延迟改进、版本号升到 v1.6。

**Architecture:** 改动集中在 5 个文件 + 测试：OnboardingScreen/OnboardingViewModel（弃用 + 默认值）、ShowPreset/ShowPresetTest（摘要纯函数 + 3 组新测试）、VoyageRepository/EventRepository（insertAll 合并 + guard 目录派生）、CruiseNavHost/strings.xml（弹窗改造）、build.gradle.kts（版本号）。全部为本地小改动，无 DB 迁移。

**Tech Stack:** Kotlin, Jetpack Compose Material3, JUnit 4（已有 domain 测试基建）。

## Global Constraints

- 只修改各任务指定的文件；提交时只 `git add` 本任务涉及的文件（工作区有无关的 APK/截图等未提交改动，不要碰）。
- `menuAnchor` 修复必须用 `ExposedDropdownMenuAnchorType.PrimaryNotEditable, enabled = true`（两处字段都是 `readOnly`）。
- `OnboardingState` 默认值从 `BUILT_IN_SHIPS[0]` 派生（不硬编码字符串/数字）；`selectedScheduleIndex` 保持 -1（船期手动选）。
- `presetShowsSummary()` 输出格式（唯一真源）：每行 `"· {title}（{dayLabel} {countLabel}）"`，行间 `\n` 连接；`dayLabel` = 范围天 `"第${dayOffsets.first()}天起每天"` / 固定天 `"第${dayOffsets.joinToString("、")}天"`；`countLabel` = dinnerLinked `"1场（按晚餐时段）"` / `"${startTimes.size}场"`。
- 弹窗消息 = `preset_shows_dialog_header` + `"\n\n"` + `presetShowsSummary()` + `"\n\n"` + `preset_shows_dialog_footer`（header/footer 在 strings.xml；标题/确认按钮字符串不变）。
- `resyncShowTimes` 的已知时间和 key 都从 `DISNEY_ADVENTURE_SHOWS` 派生（`filter { it.dinnerLinked }`），不再硬编码 18:00/20:30 和 key 字面量。
- `createVoyage` 演出循环直接 `presetEvents += ...`，删除独立的 showEvents 列表与第二个 `insertAll`。
- 版本号：`versionCode = 7`、`versionName = "1.6"`。
- 不新增数据库表、不新增迁移（DB version 保持 4）。

```kotlin
/** 弹窗消息中的演出列表摘要：每行 "· {title}（{天数} {场次数}）"，行间 \n 连接 */
fun presetShowsSummary(): String = DISNEY_ADVENTURE_SHOWS.joinToString("\n") { show ->
    val dayLabel = show.dailyRangeTo?.let { "第${show.dayOffsets.first()}天起每天" }
        ?: "第${show.dayOffsets.joinToString("、")}天"
    val countLabel = if (show.dinnerLinked) "1场（按晚餐时段）" else "${show.startTimes.size}场"
    "· ${show.title}（$dayLabel $countLabel）"
}
```

```kotlin
        val dinnerLinkedShows = DISNEY_ADVENTURE_SHOWS.filter { it.dinnerLinked }
        val knownShowTimes = dinnerLinkedShows.flatMap { it.startTimes }.toSet()
```
