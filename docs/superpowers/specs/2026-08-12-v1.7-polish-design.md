# v1.7 改进设计规格（hourHeight 默认 120 / 演出卡片贪心分级 / 文案省空间）

## Overview
v1.7 基础上三项改进（版本号不变，保持 versionCode 8 / versionName "1.7"）：(1) 每小时高度默认 120、范围 60–180、6dp 一档；(2) 演出卡片按本体高度贪心分级显示（3 行 / 2 行 / 1 行，信息分配随空间自适应）；(3) "演出等待入场"→"候场"、主界面甲板格式 "Deck 6"→"D6"（编辑/引导界面保持 Deck）。

## 1. 每小时高度

| 位置 | 现在 | 改为 |
|---|---|---|
| `SettingsStore` AppSettings `hourHeightDp` 默认 | 60 | **120** |
| `SettingsViewModel.setHourHeight` | `coerceIn(36, 140)` | `coerceIn(60, 180)` |
| `DisplayRangePanel` Slider | `valueRange = 36f..140f, steps = 12` | `valueRange = 60f..180f, steps = 19` |

- 6dp 一档（60/66/…/174/180）：60 分钟每小时对应 1/2/3 dp 每分钟的整倍数关系
- 已存过设置的用户保留各自的值（默认值语义，只影响新用户/未设置时）
- 滑块 steps = 19（20 档 − 2 端点）

## 2. 演出卡片贪心分级

### 现状
演出+30 分钟候场段合并卡片；候场段固定单行"演出等待入场 · 地点 · 开始时间"，本体（演出段）在 hasWaitSegment 时只显示 chip+标题——地点时间一股脑塞候场段，信息分配不合理。

### 分级规则（贪心，按本体剩余高度）
`bodyHeightDp = heightDp − waitSegmentHeightDp − 2dp`（2dp 为候场段与本体间 spacer）。行高基准：第 1 行 bodySmall 20dp + 其余行 labelSmall 16dp + 6dp 纵向 padding → 2 行 ≈ 42dp、3 行 ≈ 58dp（实现阈值 TWO_LINE_MIN_DP = 42.dp、THREE_LINE_MIN_DP = 58.dp）。

| 本体高度 | 本体显示 | 候场段右侧显示 |
|---|---|---|
| ≥ 58dp（3 行） | 第 1 行 类别 chip + 演出名 / 第 2 行 地点 / 第 3 行 时间范围 | 只显示"候场" |
| ≥ 42dp（2 行） | 第 1 行 类别 chip + 演出名 / 第 2 行 地点 | "候场 · 开始时间" |
| ≥ 22dp（1 行，TITLE_RESERVE 钳制保证） | 第 1 行 演出名（labelSmall） | "候场 · 地点 · 开始时间"（现状形态） |

- 阈值常量：`TWO_LINE_MIN_DP = 42.dp`、`THREE_LINE_MIN_DP = 58.dp`（EventCard 内）
- 非 show 事件（`hasWaitSegment == false`）与 compact 分支保持现有逻辑不变
- 分级只作用于"有候场段且非 compact"的卡片；时间统一用 `formatStart`（开始时间 HH:mm，省空间）
- 效果（新默认 120dp/h）：海洋奇遇/回忆（60 分钟 → 本体 118dp）3 行全显；扬帆起航（30 分钟 → 本体 58dp）3 行全显；海洋奇缘（15 分钟 → 本体 28dp）1 行；狮子王烟花（10 分钟 → 本体 26dp 钳制）1 行

## 3. 文案省空间

### 3a. "演出等待入场" → "候场"
EventCard 候场段文本（含贪心分级三种形态的右侧文案）统一用"候场"。strings.xml 无此字符串，直接代码字面量（与现有 "演出等待入场" 一致的处理方式）。

### 3b. 主界面 D 格式
`formatLocation` 加参数：

```kotlin
fun formatLocation(deck: Int?, zone: ShipZone?, placeName: String?, compact: Boolean = false): String?
```

- `compact = true` 时前缀 `"D"`（"D6 船中 花园舞台"）；默认保持 `"Deck 6 船中 花园舞台"`
- **传 compact = true**：`EventCard`（时间轴卡片）、`NowBanner`（时间轴横幅）——主界面
- **保持 Deck（不传）**：`ReminderScheduler` 通知正文、`LocationPicker` 手拼文本、引导页——非主界面/不省空间处
- `LocationFormatterTest` 补 compact 用例（"D6 船中 花园舞台"、"D7 花园"、null deck → null）
