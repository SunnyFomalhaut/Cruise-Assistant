# v1.1 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Cruise Assistant to v1.1 by adding a custom adaptive launcher icon and configuring Gradle release build output naming to `CruiseAssistant-v1.1.apk`.

**Architecture:** Standard Android 8.0+ adaptive icon XML resources linked in AndroidManifest.xml, combined with AGP variant output naming DSL configuration in `app/build.gradle.kts`.

**Tech Stack:** Android / Kotlin DSL / Android Gradle Plugin / XML Drawables

## Global Constraints

- Version Name: `"1.1"`
- Version Code: `2`
- APK Output Name: `CruiseAssistant-v1.1.apk`
- Icon Style: Scheme A (Modern Ocean Theme Adaptive Icon)

### Task 2: Configure Versioning and Custom APK Output Name in Gradle

**Files:**
- Modify: `app/build.gradle.kts`

- [ ] **Step 1: Bump version and add variant output naming logic in app/build.gradle.kts**

In `app/build.gradle.kts`:
Change:
```kotlin
        versionCode = 1
        versionName = "1.0"
```
To:
```kotlin
        versionCode = 2
        versionName = "1.1"
```

And inside `android { ... }` block, add:
```kotlin
    applicationVariants.all {
        outputs.all {
            val output = this as? com.android.build.gradle.internal.api.BaseVariantOutputImpl
            output?.outputFileName = "CruiseAssistant-v${versionName}.apk"
        }
    }
```

- [ ] **Step 2: Commit build.gradle.kts updates**

```bash
git add app/build.gradle.kts
git commit -m "build: bump version to v1.1 and name release apk CruiseAssistant-v1.1.apk"
```
