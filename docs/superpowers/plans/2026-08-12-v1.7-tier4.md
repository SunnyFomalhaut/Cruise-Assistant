# v1.7 分级中间档实施计划（候场区两行）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 演出卡片分级新增 tier 4：演出区只够 1 行、候场区够 2 行时，候场区显示两行（"候场 · 时间" + 地点），演出区 1 行演出名。版本号不变（8/"1.7"）。

**Architecture:** 单文件改动（EventCard.kt）：`showTier` 判定加 `waitTwoLines` 分支（tier 4），候场段渲染分叉（tier 4 两行 / 其余单行 waitText），演出区单行标题分支扩为 `showTier == 1 || showTier == 4`。

**Tech Stack:** Kotlin, Jetpack Compose。

## Global Constraints

- 只修改 `app/src/main/java/com/cruise/assistant/ui/timeline/EventCard.kt`；提交时只 `git add` 这一个文件。
- 版本号不变（不要动 build.gradle.kts）。
- 新常量：`WAIT_TWO_LINE_MIN_DP = 36.dp`（两行 labelSmall 16dp + 4dp padding）。
- `showTier` 判定顺序：`!hasWaitSegment → 0`；body ≥ 58 → 3；body ≥ 42 → 2；waitHeight ≥ 36 → **4**；否则 → 1。
- tier 4 候场区：第 1 行 `"候场 · ${formatStart(event)}"`（斜体粗体）、第 2 行 `location`（斜体），各 maxLines=1 ellipsis；演出区与 tier 1 共用单行标题渲染（含冲突 "!"）。
- 不新增 Room 表/迁移（DB version 4）。

### Task 1: EventCard tier 4 实现

**Files:**
- Modify: `app/src/main/java/com/cruise/assistant/ui/timeline/EventCard.kt`

- [ ] **Step 1: 常量**

EventCard.kt 顶部常量区（`WAIT_TEXT_MIN_DP` 之后）加：

```kotlin
/** 候场区能显示两行内容的最小高度（两行 labelSmall 16dp + 4dp 纵向 padding） */
private val WAIT_TWO_LINE_MIN_DP = 36.dp
```

- [ ] **Step 2: showTier 加 tier 4 分支**

把：

```kotlin
    val bodyHeightDp = heightDp - waitSegmentHeightDp - 2.dp
    val showTier = when {
        !hasWaitSegment -> 0
        bodyHeightDp >= THREE_LINE_MIN_DP -> 3
        bodyHeightDp >= TWO_LINE_MIN_DP -> 2
        else -> 1
    }
```

替换为：

```kotlin
    val bodyHeightDp = heightDp - waitSegmentHeightDp - 2.dp
    // 候场区是否够显示两行（tier 4 用）
    val waitTwoLines = waitSegmentHeightDp >= WAIT_TWO_LINE_MIN_DP
    val showTier = when {
        !hasWaitSegment -> 0
        bodyHeightDp >= THREE_LINE_MIN_DP -> 3
        bodyHeightDp >= TWO_LINE_MIN_DP -> 2
        waitTwoLines -> 4
        else -> 1
    }
```

- [ ] **Step 3: 候场段渲染分叉**

候场段 Column 内，把：

```kotlin
                    Text(
                        text = waitText,
                        style = MaterialTheme.typography.labelSmall,
                        fontStyle = FontStyle.Italic,
                        fontWeight = FontWeight.Bold,
                        color = textColor.copy(alpha = 0.9f),
                        maxLines = 1,
                        overflow = TextOverflow.Ellipsis,
                    )
```

替换为：

```kotlin
                    if (showTier == 4) {
                        // 候场区两行：第 1 行"候场 · 开始时间"，第 2 行地点（充分利用空间）
                        Text(
                            text = "候场 · ${formatStart(event)}",
                            style = MaterialTheme.typography.labelSmall,
                            fontStyle = FontStyle.Italic,
                            fontWeight = FontWeight.Bold,
                            color = textColor.copy(alpha = 0.9f),
                            maxLines = 1,
                            overflow = TextOverflow.Ellipsis,
                        )
                        location?.let {
                            Text(
                                text = it,
                                style = MaterialTheme.typography.labelSmall,
                                fontStyle = FontStyle.Italic,
                                color = textColor.copy(alpha = 0.75f),
                                maxLines = 1,
                                overflow = TextOverflow.Ellipsis,
                            )
                        }
                    } else {
                        Text(
                            text = waitText,
                            style = MaterialTheme.typography.labelSmall,
                            fontStyle = FontStyle.Italic,
                            fontWeight = FontWeight.Bold,
                            color = textColor.copy(alpha = 0.9f),
                            maxLines = 1,
                            overflow = TextOverflow.Ellipsis,
                        )
                    }
```
