# v1.6 收尾改进设计规格（菜单弃用修复 / 默认探险号 / 延迟项落实 / 版本号）

## Overview
v1.6 四项改动：(1) 修复 OnboardingScreen 两处 `menuAnchor()` 弃用警告；(2) 引导页默认选中探险号（船期仍手动选）；(3) 落实预置演出功能遗留的 6 项延迟改进；(4) 版本号升级到 v1.6。

## 1. menuAnchor 弃用修复

`OnboardingScreen.kt:96` 与 `:153` 的两处 `Modifier.menuAnchor()`（无参重载已弃用）改为：

```kotlin
modifier = Modifier.menuAnchor(ExposedDropdownMenuAnchorType.PrimaryNotEditable, enabled = true).fillMaxWidth()
```

- 两个字段（船名、船期）都是 `readOnly = true` 的 OutlinedTextField，锚点类型用 `PrimaryNotEditable`（只读下拉的推荐类型）。
- 新增 import：`androidx.compose.material3.ExposedDropdownMenuAnchorType`。
- 验证：`./gradlew :app:compileReleaseKotlin` 不再输出这两个弃用警告。

## 2. 引导页默认选中探险号

`OnboardingState`（OnboardingViewModel.kt）默认值修改：

| 字段 | 原默认 | 新默认 |
|---|---|---|
| `selectedShipIndex` | -1（自定义） | 0（Disney Adventure） |
| `shipName` | "" | `BUILT_IN_SHIPS[0].name`（"Disney Adventure"） |
| `maxDeck` | 20 | `BUILT_IN_SHIPS[0].maxDeck ?: 20`（19） |
| `minDeck` | 1 | `BUILT_IN_SHIPS[0].minDeck ?: 1`（5） |
| `selectedScheduleIndex` | -1 | -1（不变，船期手动选） |

- 默认值从 `BUILT_IN_SHIPS[0]` 派生，不硬编码 19/5/"Disney Adventure"，避免与目录漂移。
- 效果：引导页打开时船名=探险号、甲板范围 5-19F 锁定显示、船期下拉出现待选；点船名下拉可切"自定义船名…"回自由输入。
- 默认提交（内置船 + 自定义船期）合法：`shipPresetName` 非 null，演出照常生成、弹窗照常出现（与现有逻辑一致，无新代码）。

## 3. 延迟改进项落实（6 项）

### 3a. 19:00 边界测试（ShowPresetTest 新增）
```kotlin
@Test fun dinnerLinked_at1900_returns1800Show() {
    assertEquals(LocalTime.of(18, 0), pickDinnerLinkedTime(LocalTime.of(19, 0)))
}
@Test fun dinnerLinked_1859_returns2030Show() {
    assertEquals(LocalTime.of(20, 30), pickDinnerLinkedTime(LocalTime.of(18, 59)))
}
```

### 3b. 非原子 insertAll 合并（VoyageRepository.createVoyage）
删掉独立的 `showEvents` 列表与第二个 `eventDao.insertAll(showEvents.map { it.toEntity() })`，演出生成循环直接 `presetEvents += CruiseEvent(...)`，最终保持单个 `eventDao.insertAll(presetEvents.map { it.toEntity() })`。

### 3c. resyncShowTimes guard 从目录派生（EventRepository）
硬编码 `{18:00, 20:30}` 改为：
```kotlin
val knownShowTimes = DISNEY_ADVENTURE_SHOWS
    .filter { it.dinnerLinked }
    .flatMap { it.startTimes }
    .toSet()
```
循环内判断 `entity.startTime in knownShowTimes`。映射知识只剩 `pickDinnerLinkedTime` 一处。新增 import `com.cruise.assistant.domain.DISNEY_ADVENTURE_SHOWS`。

### 3d. 弹窗移入 else 分支（CruiseNavHost）
`if (showPresetShowsDialog) { AlertDialog(...) }` 从 if/else（TimelineLoading/TimelineScreen）之后，移入 `else` 块内 TimelineScreen 调用之后——`current == null` 的加载窗口不再在 spinner 上叠弹窗。

### 3e. 弹窗消息目录驱动
`ShowPreset.kt` 新增纯函数：
```kotlin
fun presetShowsSummary(): String = DISNEY_ADVENTURE_SHOWS.joinToString("\n") { show ->
    val dayLabel = show.dailyRangeTo?.let { "第${show.dayOffsets.first()}天起每天" }
        ?: "第${show.dayOffsets.joinToString("、")}天"
    val countLabel = if (show.dinnerLinked) "1场（按晚餐时段）" else "${show.startTimes.size}场"
    "· ${show.title}（$dayLabel $countLabel）"
}
```
strings.xml：`preset_shows_dialog_message` 删除，拆成：
- `preset_shows_dialog_header`：已按迪士尼探险号的演出安排，将以下演出加入日程表第二栏：
- `preset_shows_dialog_footer`：长按演出卡片可编辑或删除。
- `preset_shows_dialog_title` / `preset_shows_dialog_ok` 保留不变。

CruiseNavHost 拼装：`header + "\n\n" + presetShowsSummary() + "\n\n" + footer`。

### 3f. 无重叠测试（ShowPresetTest 新增）
遍历 `DISNEY_ADVENTURE_SHOWS`，对每个出现的天（固定天 dayOffsets + 范围天 2..4）收集所有场次区间（`startMinute..startMinute+duration`），两两断言不重叠。钉住规格"全航次无时间重叠"保证。dinner-linked 演出的两个候选场次都在集合内（候选间本身不重叠，不会误报）。
