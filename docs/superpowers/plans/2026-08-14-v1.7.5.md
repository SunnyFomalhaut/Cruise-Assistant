- [ ] **Step 2: RED → 实现**

ShipPreset.kt 追加：

```kotlin
/** 登船时间段选项：11:45 起每 15 分钟一段至 3:00（次日凌晨），共 60 段（迪士尼探险号 PAT） */
fun boardingSlots(): List<LocalTime> {
    val startMin = 11 * 60 + 45          // 11:45
    val endMin = 24 * 60 + 3 * 60        // 次日 3:00
    return buildList {
        var m = startMin
        while (m <= endMin) {
            add(LocalTime.of((m / 60) % 24, m % 60))
            m += 15
        }
    }
}
```
