# 迪士尼探险号浮动演出心愿单待定档与日程流转 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将迪士尼探险号（Disney Adventure）非固定日期的 5 部浮动演出从创建航次自动排期中剔除并自动播种至心愿单，狮子王烟花地点更新为 `阳光泳池 Sunnyside Pool` 并带观赏提示备注，在 Android 与 iOS 双端支持从心愿单一键定档排入时间轴。

**Architecture:** 
- **演出目录分流**：在 `ShowPreset` 中增加可选 `note` 字段并校准狮子王烟花；划分为 `TIMELINE_AUTO_GENERATED_SHOWS`（3 部高确定性）与 `WISHLIST_SEED_SHOWS`（5 部浮动演出）。
- **航次创建播种**：`VoyageRepository.createVoyage` 仅将确定项排入时间轴，浮动演出以“演出”类别幂等插入心愿单。
- **心愿单转入日程**：心愿单卡片提供“📅 排入日程”动作，弹窗指定日期与时间后自动调用 `EventRepository.addEvent` 计算 Lane 排期并标记心愿完成。

**Tech Stack:** 
- Android: Kotlin, Jetpack Compose, Room DB, Kotlin Coroutines & Flow, StateFlow, JUnit4
- iOS: Swift 5.9, SwiftUI, XCTest, Combine, Sendable

## Global Constraints
- 迪士尼探险号时间轴自动生成演出严格限制为 3 部：`show_set_sail`（扬帆起航）、`show_seas_adventure`（海洋奇遇）、`show_lion_king`（狮子王烟花）。
- 狮子王烟花地点必须使用 `阳光泳池 Sunnyside Pool`（与 `locations.json` 保持一致），预置备注为：“烟花在右舷，可以在这个泳池旁边的空地或者18甲左舷走廊（人比较多）”。
- 浮动演出播种到心愿单时必须保持幂等性（通过标题比对已存在项），不得产生重复项。
- 时间轴新建日程的预置演出选择器（`ShowPresetPicker`）必须完整保留全部 8 部演出。

```kotlin
                deck = item.deck,
                title = item.title,
                presetKey = null,
            )
            val event = CruiseEvent(
                date = date,
                startTime = startTime,
                durationMinutes = maxOf(15, durationMinutes),
                categoryId = item.categoryId,
                title = item.title,
                deck = item.deck,
                zone = item.zone,
                placeName = item.placeName,
                note = item.note,
                lane = 0,
                isSystemGenerated = false,
                waitMinutes = waitMinutes,
            )
            eventRepo.addEvent(event, recurring = false)
            wishlistRepository.toggleCompleted(item.id, true)
            onSuccess()
        }
    }
```
